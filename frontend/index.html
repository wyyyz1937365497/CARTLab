CART 决策树的四个核心机制

CART（分类与回归树）用基尼指数衡量节点不纯度，在相邻取值中点上穷举阈值做二分裂，按停止条件递归生长，最后用代价复杂度剪枝在过拟合的满树与欠拟合的浅树之间，以验证集选出合适的复杂度。

1基尼指数与加权基尼

基尼指数表示从节点内随机抽两个样本、类别不一致的概率：纯节点为 0，三类均匀混合时为 2/3。分裂以「加权后基尼最小 / 增益最大」为准。

Gini(t) = 1 − Σk pk²
Ginisplit = (nL/n)·Gini(tL) + (nR/n)·Gini(tR)
Gain = Gini(t) − Ginisplit

Iris 根节点：Gini = 0.667；按「花瓣长度 ≤ 2.45」分裂后降至 0.333，增益 0.333

2阈值候选与高效扫描

每个特征先排序，候选阈值取相邻不同取值的中点；排序一次后从左到右滚动维护左右计数，每个候选的加权基尼 O(1) 更新，避免对每个阈值重算。

t ∈ { (xi + xi+1)/2 | xi < xi+1 }
单节点代价 O(F · n log n)，F 为特征数

90 个训练样本、4 特征：全部节点共评估 301 个候选阈值

3递归停止条件（预剪枝）

满足任一条件即不再分裂、标记为叶节点；叶节点的预测类别取该节点内样本最多的类。

  • 节点已纯：只有单一类别（reason = pure）
  • 深度达到 max_depth（留空则不限制）
  • 节点样本数不足以再分成两片叶
  • 所有候选被 min_samples_leaf 禁止 → 无有效划分
  • 最大增益 ≤ min_gain → 划分无收益

4代价复杂度剪枝（CCP）

把「子树 t 整体换成叶」带来的训练风险上升折算成每片叶的代价 αeff，每轮剪掉最弱链接（αeff 最小）的子树，得到 α 递增的嵌套子树序列。

Rα(T) = R(T) + α·|T|，R(T) = Σleaf (nt/n)·Gini(t)
αeff(t) = (R(t) − R(Tt)) / (|Tt| − 1)

训练准确率随剪枝单调不增，无法提示过拟合位置；因此用验证集在序列中选准确率最高的树（平局取叶更少者），α 也可手动指定。

Iris：基线 13 节点 → 剪枝后 7 节点，验证准确率不降

实验流程

与「实验台」页各步骤一一对应
加载 Iris→ 按种子分层划分 90/30/30→ 递归二分裂（记录帧）→ CCP 剪枝序列→ 验证集选 α→ 三个子集评估 + PCA 投影
  • 数据划分与树的随机性完全由种子决定：同一种子逐位复现。
  • 帧序列记录每次「选中划分 / 展开子树 / 标记叶节点」，可在时间轴回放建树过程。
